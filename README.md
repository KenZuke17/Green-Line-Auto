# Green Line Auto Service

A React-based vehicle service and inventory management application for an auto service center.

## Tech stack
- React
- Vite
- Electron
- SQL.js
- JavaScript / JSX

## Features
- Vehicle lookup and details
- Service history tracking
- Inventory management
- Add vehicle workflows
- Dashboard overview

## Getting started

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build:renderer
npm run dist
```

## Project purpose
This project is designed to help manage vehicle records, service work, and inventory for a car service center in a desktop application environment.
